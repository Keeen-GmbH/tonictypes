===============
Getting started
===============

Follow these steps to create your first Tonictypes datatype and show records
in the frontend.

.. toctree::
   :maxdepth: 1
   :titlesonly:

   Fields
   Datatypes
   RecordsAndTable
   Templating

Quick path
==========

1. **Create fields** — at least one field (for example title as Input)
2. **Create a datatype** — assign fields, choose icon/label
3. **Create / update table** — generate SQL columns + TCA
4. **Create records** — use the list module for the new table
5. **Templating** — create Fluid files and register them in TypoScript
6. **Plugin** — place List or Detail on a page

Optional helpers
================

* **Dashboard > Predefined Datatype Import** — load the bundled sample datatype
* **System > Export / Import** — move datatype structures between instances
  (see :ref:`transfer`)
