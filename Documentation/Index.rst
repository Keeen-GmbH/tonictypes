Tonictypes
===========

----

Tonictypes lets you build TCA-powered record types in the TYPO3 backend
without writing a custom extension for every use case. Create fields and
datatypes, generate tables and TCA, then render records with Fluid and
frontend plugins.

This manual covers **Tonictypes Core** (`k3n/tonictypes`) and documents
**Tonictypes Professional** (`k3n/tonictypes_pro`) features that extend Core.
